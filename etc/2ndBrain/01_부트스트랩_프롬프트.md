# 부트스트랩 프롬프트 (그대로 복사해서 클로드 코드에 붙여넣기)

> 옵시디언 볼트 폴더에서 `claude`를 실행한 뒤, 아래 프롬프트를 통째로 붙여넣으면 됩니다.
> **외부 문서 없이 이것 하나로 3층 구조(raw/wiki/CLAUDE.md)가 자동 생성됩니다.**

---

```
나만의 지식 위키를 만들 거야. 자료를 넣으면 네가 읽고 정리해서 위키로 만들어주고,
나는 필요할 때 질문만 하면 돼.

나에 대해:
- 나는 여러 분야의 정보를 다루는 지식 노동자야 (업무 + 학습 + 콘텐츠/아이디어)
- 내가 주로 넣을 자료:
  - 웹에서 스크랩한 기사, 새 도구/트렌드 소식
  - 강의·영상·팟캐스트에서 배운 내용 정리
  - 책에서 얻은 인사이트, 멘탈모델, 인상 깊은 문장
  - 업무/회의 메모, 결정 사항, 할 일
  - 개인 아이디어 (콘텐츠, 프로젝트 등)

다음을 만들어줘:
1. CLAUDE.md — 위키 관리 규칙(Schema). "자료 넣기 / 질문하기 / 건강검진" 3가지 운영 모드 정의
2. raw/ 폴더 — 원본 자료 보관 (내가 넣고, 너는 읽기만)
3. wiki/ 폴더 — 정리된 지식 저장 (네가 작성·관리)
4. wiki/index.md — 전체 목차 (카테고리별로, 자료 넣을 때마다 업데이트)
5. wiki/log.md — 작업 이력 (append-only)

규칙:
- raw, wiki 모두 하위 폴더 없이 '플랫'하게 관리해줘. 분류는 index.md에서 카테고리로 정리.
- 위키 페이지는 마크다운으로, 페이지 간 [[위키링크]]로 적극 교차참조해.
- 모든 위키 페이지 맨 앞에 > callout 블록으로 "이 내용에서 내가 가져갈 핵심 한 줄"을 먼저 넣어줘.
- 파일명: raw는 'YYYY-MM-DD_간단설명.md', wiki는 케밥케이스(한글 허용).

먼저 폴더 골격과 CLAUDE.md부터 만들고, 다 만들면 구조를 요약해서 보여줘.
```

옵시디언 왼쪽에 **`raw` / `wiki` 폴더 + `CLAUDE.md` / `index.md` / `log.md`** 다섯 개가 보이면 성공입니다.
안 보이면 클로드가 볼트 폴더가 아닌 다른 곳에서 켜졌을 수 있어요 → 터미널에서 `pwd`로 위치 확인, 또는 "폴더 구조 정리해줘"로 수정 요청.
