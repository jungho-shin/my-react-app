# 폴더 구조 템플릿 (부트스트랩이 만들어주는 형태)

> 부트스트랩 프롬프트를 돌리면 클로드가 자동으로 만들어줍니다.
> 수동으로 만들고 싶으면 아래 구조 그대로 폴더/파일을 생성하세요.

```
내-지식위키/                (옵시디언 볼트 = 이 폴더)
├── CLAUDE.md              ← 규칙서 (배포팩 02 참고)
├── raw/                   ← 원본 자료. 내가 넣고, 클로드는 읽기만.
│   └── (여기에 기사·노트·메모·PDF 등을 그냥 넣는다)
└── wiki/                  ← 정리된 지식. 클로드가 작성·관리.
    ├── index.md           ← 전체 목차
    ├── log.md             ← 작업 이력
    └── (클로드가 만드는 위키 페이지들)
```

> **핵심 원칙**
> - `raw/`·`wiki/` 모두 하위 폴더 없이 **플랫**하게. 분류는 폴더가 아니라 `index.md`에서 카테고리로.
> - 볼트는 옵시디언에서 **"Open folder as vault"** 로 열 것 ('Create new vault' 쓰면 폴더가 중첩될 수 있음).
> - 클로드 코드는 **이 볼트 폴더 안에서** 실행(`claude`). 작업 디렉토리 = 볼트.

---

## 시작용 `wiki/index.md` (초기 상태)

```markdown
# 지식 위키 — 전체 목차
> 마지막 업데이트: (자동)

## AI·도구
_아직 등록된 페이지가 없습니다. raw/에 자료를 넣고 "반영해줘"라고 하세요._

## 생산성·자기계발
_아직 없음_

## 마케팅·콘텐츠
_아직 없음_

## 업무·프로젝트
_아직 없음_

## 아이디어
_아직 없음_
```

## 시작용 `wiki/log.md` (초기 상태)

```markdown
# 작업 이력 (append-only)
> 자료 넣기(ingest) / 건강검진(lint) 기록이 시간순으로 쌓입니다.

## [YYYY-MM-DD] 위키 초기화
```
