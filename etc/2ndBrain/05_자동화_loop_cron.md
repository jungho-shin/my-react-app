# 자동화 — `/loop` & cron (예약 실행)

> "raw에 자료를 넣기만 하면 알아서 위키에 반영"되게 만드는 방법 두 가지.

## 방법 A — `/loop` (클로드 코드가 켜져 있는 동안)

클로드 코드 세션 안에서:
```
/loop 10분 raw에 새로 넣은 자료를 찾아서 위키에 반영해줘.
서로 다른 자료 사이에 의외의 연결점이 있으면 적극적으로 연결해줘.
```
- 10분마다 위 작업을 반복 실행합니다.
- 세션이 살아있는 동안 작동. 세션을 닫으면 멈춥니다 → 다시 켤 때 위 프롬프트를 다시 넣으면 됩니다.

## 방법 B — cron 예약 (주기적 자동 실행)

클로드 코드에 예약 작업을 걸어두면 주기적으로 실행됩니다. 세션에서:
```
매일 아침 9시에 raw의 새 자료를 위키에 반영하는 예약 작업을 만들어줘.
```
또는 직접 크론 표현식으로:
```
*/30 * * * * (30분마다) raw 새 자료를 위키에 반영하는 스케줄을 등록해줘.
```

> **⚠️ 한계 (꼭 알기):** 로컬 예약은 **컴퓨터가 켜져 있고 클로드 코드가 실행 가능한 상태**여야 돕니다. 노트북을 닫으면 안 돌아갑니다. 항상 돌리려면 늘 켜둔 PC/서버가 필요합니다.

## 팁
- 자동화는 **자료가 어느 정도 쌓인 뒤** 켜는 게 좋습니다(초기엔 수동으로 기둥 페이지부터).
- 토큰 비용이 붙는 작업이니, 주기를 너무 짧게 잡지 마세요(10~30분 권장).
- 자동 반영 후에는 가끔 `위키 건강검진 한번 하자`로 정리하면 품질이 유지됩니다.
