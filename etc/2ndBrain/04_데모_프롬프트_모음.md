# 데모 프롬프트 모음 (영상에서 쓰는 명령 전부)

> 복사해서 그대로 쓰세요. AI라 결과는 매번 조금씩 다릅니다 — 마음에 안 들면 다시/변형해서 시키면 됩니다.

## 0. 셋업
```
claude
```
(볼트 폴더에서 실행 → 첫 실행 시 브라우저 로그인)
※ 미설치 시: `npm install -g @anthropic-ai/claude-code` (유료 플랜 Pro/Max 또는 API 필요)

## 1. 부트스트랩 (3층 구조 생성)
→ 배포팩 `01_부트스트랩_프롬프트.md` 참고

## 2. 넣기 (Ingest)
```
raw에 새로 넣은 자료들을 위키에 반영해줘.
서로 다른 자료 사이에 의외의 연결점이 있으면 적극적으로 연결해줘.
```
(자료가 아주 많을 때 — 기둥 먼저)
```
카테고리별로 정보가 풍부한 핵심 페이지 10개를 먼저 만들어줘.
서로 다른 자료 간에 의외의 연결점이 있으면 적극적으로 연결해줘.
```

## 3. 찾기 (Query)
```
내 위키 전체를 참고해서, 개별 자료엔 안 보이지만 여러 개를 겹쳐 놓으면 드러나는
연결점이나 인사이트가 있으면 알려줘. 각 근거는 [[위키링크]]로 표시해줘.
```
```
내 위키에 쌓인 자료랑 인사이트를 기반으로, 다음에 만들면 좋을
콘텐츠(또는 프로젝트) 아이디어 3개를 우선순위로 추천해줘. 각각 근거도 같이.
```
```
내가 읽은 책 노트 중에서, 지금 내 고민(예: 시간 관리)에 적용할 수 있는
멘탈모델이 있으면 찾아서 정리해줘.
```

## 4. 검증 (새 대화를 열어도 그대로)
→ 현재 대화 종료 후 `/clear` 또는 새 세션
```
내가 그동안 정리해둔 지식 중에서 [최근 관심 주제]에 대해 아는 걸 정리해줘.
```

## 5. 자동화 (Loop)
```
/loop 10분 raw에 새로 넣은 자료를 찾아서 위키에 반영해줘.
서로 다른 자료 사이에 의외의 연결점이 있으면 적극적으로 연결해줘.
```
→ cron 방식은 배포팩 `05_자동화_loop_cron.md` 참고

## 6. 확장
(Claude Skills — 노트를 다른 형식으로)
```
이 노트를 발표용 슬라이드(pptx)로 만들어줘.
```
```
이 노트 내용을 옵시디언 캔버스로 시각화해줘. 핵심 개념을 노드로, 관계를 화살표로.
```
```
이 폴더 노트들을 Base(표)로 정리해줘. 제목·카테고리·수정일 컬럼으로.
```
(MCP — 외부 자료 자동 공급, 예)
```
노션 '읽은 자료' DB에서 이번 주 새 항목을 raw로 가져와서 위키에 반영해줘.
```

## 자주 막힐 때
- `claude` 안 먹힘 → 설치/터미널 재시작. `npm install -g @anthropic-ai/claude-code` 후 터미널 껐다 켜기.
- 로그인 안 뜸 → 터미널에 출력된 URL 직접 복사해 브라우저에서 열기.
- ingest가 파일 무시 → "raw의 ○○ 파일도 반영해줘"로 콕 집기.
- 엉뚱한 폴더에 생성 → `pwd`로 위치 확인, "폴더 구조 정리해줘".
- 결과가 이상 → 정상(비결정성). "다시, 더 간결하게/자세하게"로 재요청.
